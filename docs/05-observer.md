# Observer 观测面板 PRD

## 1. 产品定位（先说不是什么）

> **Observer 不是调度器。** 它不能生成 COLLAB_CALL，不能决定任务流向，不能"帮 Agent 规划下一步"。
> 它只有两个身份：**仪表盘**（看全网在发生什么）+ **刹车与开关**（人保留最终控制权）。

如果一个功能需要 Observer"判断该找谁"，那它就不属于 Observer，属于 Agent 本体的提示词。

## 2. 目标用户与场景

| 用户 | 场景 | 频率 |
|---|---|---|
| 主用户（单人） | 开新项目、看协作是否卡住、临时给某会话开跨域、紧急切会话 | 每天多次 |
| 调试中的自己 | 复现失败链路、看某条 CALL 为什么被拒、回放 Executor 动作序列 | 开发期高频 |

**核心使用时刻：**
1. "Claude 说它派工给 Qoder 了，Qoder 那边到底收到没有？" → Trace 链路
2. "这条任务卡住了 10 分钟。" → 节点状态 + 失败回执
3. "我要让国际版和国内版协作一次。" → 会话级跨域开关
4. "Executor 好像点错地方了。" → 执行日志 + 截图回放 + 全局急停

## 3. 页面结构

```
Observer
├── 总览 Dashboard      节点 / 会话 / 今日调用量 / 异常计数
├── 节点 Nodes          按域分栏的节点卡片
├── 会话 Sessions       FSID 卡片 + 操作
├── 链路 Traces         按 trace_id 的调用时序图
├── 审计 Audit          跨域 / 拒绝 / 超限事件
├── 执行 Executions     Executor 步骤回放 + 截图
└── 设置 Settings       全局急停、保留策略、token 管理
```

## 4. 模块详细需求

### 4.1 总览 Dashboard

| 元素 | 内容 |
|---|---|
| 节点统计 | 在线 / idle / degraded / offline 各几个，按域分色 |
| 会话统计 | active FSID 数、今日新增、已暂停数 |
| 调用统计 | 今日 CALL 总数、成功率、平均耗时、跨域次数 |
| 异常看板 | 近 24h 拒绝原因 Top5（如 `forbidden_cross_domain` / `session_locate_failed`） |
| 急停按钮 | **全局急停**，红色，二次确认 |

### 4.2 节点页

**布局**：左右双栏，🟦 国际域 / 🟩 国内域，**严禁合并同软件的 CN 与 INTL**。

**节点卡片字段：**

| 字段 | 说明 |
|---|---|
| `display_name` + 版本徽章 | `Qoder 国际版` / `Qoder 国内版`，徽章颜色区分域 |
| `node_id` | 小字等宽显示，便于排查 |
| 状态点 | 🟢 online / 🟡 idle / 🟠 degraded / ⚪ offline |
| `transport_type` | Tier1 绿 / Tier2 黄 / Tier3 红（直观提示稳定性） |
| `capabilities` | 能力标签 chips |
| `network_isolation_tag` | 网络分组，风控溯源用 |
| 已挂载 FSID | 折叠列表 |
| 操作 | 查看详情 / 查看日志 / 停用节点（Registry 标记 disable） |

### 4.3 会话页（最常用）

**FSID 卡片：**

| 字段 | 说明 |
|---|---|
| `title` | 大字，人读 |
| 域策略徽章 | `[同域仅允许]` 灰蓝 / `[跨域审计开启]` 橙红 |
| 暂停徽章 | `[已暂停协作]` |
| 成员节点 | 头像式 chips，鼠标悬停显示 node_id + 域 |
| 工件数 / 最后活动 | — |

**卡片操作（全部为人工动作）：**

1. 重命名会话标题
2. **开关：允许跨域审计协作** → 橙色弹窗二次确认（见 §5.1）
3. **开关：暂停本会话所有自动协作**（最高优先级刹车）
4. **手动唤起**：选择成员节点 → 拉起 App 并切到该 FSID 会话
5. **手动投递**（高级）：人工构造一条 COLLAB_CALL 投给指定节点（用于调试/补刀）
6. 查看该会话全部 Trace
7. 查看该会话审计流水
8. 解绑某节点
9. 归档 / 删除会话

### 4.4 链路页（Trace）

**视图**：横向时序图（左=时间轴，上=节点泳道）。

| 元素 | 规则 |
|---|---|
| 节点泳道 | 按域分色，同域同色系 |
| 消息箭头 | CALL 向右，REPLY 向左虚线 |
| 同域连线 | 实线 |
| 跨域连线 | **红色虚线 + 「跨域｜已审计」标签** |
| 消息节点展开 | `msg_id` / `intent` / `call_depth` / `status` / `elapsed_ms` / `payload` 摘要 |
| 失败节点 | 红色边框 + 错误码 |
| 顶部 | `trace_id` 可复制、可跳到 audit 记录 |

**筛选**：时间范围、fsid、节点、status、是否跨域。

### 4.5 审计页

**只收录这几类事件**（不收录全部流量，否则日志爆炸）：

| 类型 | 记录内容 |
|---|---|
| 跨域投递 | caller/target 域、payload hash、前 200 字、命中规则 |
| 被拒绝 | 错误码、原因、信封摘要 |
| 深度超限 | trace 链快照 |
| Executor 高危动作 | 动作、路径/命令 digest、是否人工放行 |
| 人工操作 | 谁在什么时候开了什么开关 |

**能力**：筛选、导出 CSV（合规留痕）、一键清理（保留期外）。

### 4.6 执行页（Executor）

| 区域 | 内容 |
|---|---|
| 任务列表 | 按时间倒序，显示 caller / intent / status / 耗时 |
| 步骤时间线 | 每步：action、窗口标题、是否 verified、耗时 |
| 截图查看器 | 单击放大，按 step_idx 定位 |
| 回放 | 逐步骤回看（不做真实重放，避免二次误操作） |
| 急停 | 单任务取消 + 全局 Executor 急停 |

### 4.7 设置

| 项 | 说明 |
|---|---|
| 全局急停 | 断开 NATS 或下发全节点 suspend |
| 保留策略 | 链路日志 30 天 / 审计 180 天 / 截图 7 天 |
| 本机 token | 各 Sidecar HTTP 接口的访问令牌查看/轮换 |
| 高危权限总闸 | `ALLOW_HIGH_RISK` 的可视化开关（与 .env 联动，需二次确认） |

## 5. 关键交互设计

### 5.1 开跨域的确认弹窗（必须拦住手滑）

```
┌─────────────────────────────────────────────┐
│ ⚠️ 开启跨域协作？                            │
│                                             │
│ 会话：昆仑芯 Triton 算子开发                  │
│ 方向：国际域 ⇄ 国内域                        │
│                                             │
│ 开启后：                                     │
│  · 两域节点可互相派工                        │
│  · 所有跨域消息将留存审计日志（含内容摘要）    │
│  · 建议用完立即关闭                          │
│                                             │
│ 禁止传输：内部业务资料 / 未脱敏数据 / 凭证     │
│                                             │
│        [取消]        [我已知晓，确认开启]     │
└─────────────────────────────────────────────┘
```

### 5.2 手动唤起节点的提示

唤起前显示：`即将唤起「Qoder 国际版」（node_id: qoder-intl-01，安全域: intl）`，避免点错版本。

### 5.3 消息来源标记（Agent 侧配合）

联邦协作注入的消息在 App 会话内带前缀标记（如 `[FACP:tr-xxx]`），Observer 的链路页要与之一一对应，便于人对账。

## 6. 非功能需求

| 项 | 要求 |
|---|---|
| 形态 | 本地 Web 应用，`http://127.0.0.1:8902` |
| 技术栈 | 轻量优先：FastAPI + HTMX + 原生 CSS（不引入重型前端框架） |
| 数据源 | Registry / FSHub 只读查询；写入仅限人工操作产生的记录 |
| 刷新 | 事件推送（SSE）为主，轮询兜底（5s） |
| 性能 | 1000 条 Trace 内页面渲染 < 1s；日志量超过阈值自动分页/归档 |
| 安全 | 本机 token 鉴权；不监听 0.0.0.0，仅 127.0.0.1 |
| 可用性 | Observer 挂了不影响 Mesh 运行（纯旁路） |

## 7. 明确不做（防范围膨胀）

- ❌ 自动规划 / 自动派工 / 自动重试编排
- ❌ 全局一键跨域（只能会话级）
- ❌ 多用户权限体系（单人系统）
- ❌ 云端部署（本机工具）
- ❌ 修改各 Agent 的会话内容（只能查看与开关）

## 8. 迭代计划

| 版本 | 范围 |
|---|---|
| v0.1（本期） | 节点列表 + 会话卡片 + 跨域开关 + 链路列表（表格式，非图形） |
| v0.2 | 时序图可视化 + 审计页 + 导出 |
| v0.3 | Executor 执行回放 + 截图查看 + 人工确认弹窗 |
| v0.4 | SSE 实时刷新 + 异常看板 |

## 9. 验收标准（v0.1）

```
[ ] 能在一个页面看到所有节点，CN/INTL 严格分栏不合并
[ ] 能看到每个 FSID 的域策略与成员节点
[ ] 能在会话级打开/关闭跨域，且有关闭后的即时生效验证
[ ] 能按 trace_id 列出一次协作的全部消息与状态
[ ] 全局急停可用，执行后新 CALL 全部被拒
[ ] Observer 停止运行后，Mesh 与 Agent 协作不受影响
```
